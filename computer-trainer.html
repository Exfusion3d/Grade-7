How it works. Each card has 4 steps: 🔑 spot the keyword (tap it: it tells you which answer to write), 🧠 remember the answer in your head, then look at it, ✍️ cover and write it (on paper, or type it), and ✔ check it. Then be honest: ✔ Got it moves the card up a box and you see it again later; 〰 Nearly keeps it where it is; ✗ Not yet sends it back to box 1, so it comes back tomorrow (and once more today). An answer is mastered when it reaches box 4.
