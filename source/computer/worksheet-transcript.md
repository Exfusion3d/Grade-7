## Short questions (the answers to learn and write)

**Q1. What do you know about HTML?** → c01
HTML stands for Hypertext Markup Language. It was developed in the year 1990 by the scientist Tim Berners-Lee.

**Q2. What's the use of HTML?** → c01
HTML is mainly used to create web pages that are displayed on the World Wide Web. Each page contains a series of
connections to other pages called hyperlinks.

**Q3. Write any three features of HTML 5?** → c01
1. HTML documents are simple text files. 2. HTML is not a case sensitive language. 3. HTML has many tags to make web pages.

**Q4. Define HTML Editors and Text Editors.** → c01
We can create HTML document using an HTML editor or any text editor. HTML editors are Adobe Dreamweaver, Ultra-Edit,
TextMate. Text editors are Notepad, Notepad++. We can create our HTML documents using Notepad.

**Q5. How can we view the HTML document?** → c01
After creating and saving an HTML document we can view it by double clicking on the HTML document. We can also open
an HTML file by opening Microsoft Edge by clicking on its icon on the desktop or the taskbar and then pressing
Control + O keys. `[FIX]` sheet has "the task"

**Q6. What do you know about HTML tags?** → c02
Tags are elements that are used to specify the structure of an HTML document. HTML tags begin with the less than
character (<) and end with the greater than symbol (>), which are called angular brackets.

**Q7. What is the difference between opening and closing tags?** → c02
In HTML, most tags have an opening and a closing tag. For example `<HTML>` is the opening tag and `</HTML>` is the
closing tag. The tags which have both opening and ending tags are called container tags.

**Q8. What do you know about CSS?** → c05
CSS stands for Cascading Style Sheets. CSS is used to style HTML pages and it's used to specify how HTML elements are
displayed.

**Q9. List down the different types of CSS?** → c06
1. Inline style sheet 2. Internal style sheet 3. External style sheet

**Q10. Define inline style sheet.** → c06
The inline style sheet is used to apply the style to a single HTML element using the style attribute.

**Q11. What do you know about computer programming?** → c07
A sequence of instructions given to the computer to perform a particular task is called a program. These programs are
created using programming languages. The process of creating a program is also known as programming.

**Q12. Write the names of types of computer programming languages?** → c07
There are three main types: 1. Machine level language 2. Assembly level language 3. High level language

**Q13. Describe a language translator?** → c07
A language translator such as a compiler or interpreter is needed to convert the high level language code into
machine code. A computer understands only machine language.

**Q14. What do you know about Python?** → c08
Python is a high level programming language. It has simple syntax which makes it easy to read and write. It was
developed in 1991 at the National Research Institute for Mathematics and Computer Science in the Netherlands.

**Q15. Write any 2 features of Python?** → c08
Python is easy to learn and use as compared to other programming languages. Python can perform complex tasks using
less code.

**Q16. What is an Object Oriented procedure?** → c08
Python supports Object Oriented procedure. An Object Oriented procedure helps the programmer to write reusable code
and develop applications using less code as compared to other programming languages.

**Q17. Describe Interactive Mode of Python while writing a code.** → c08
In the Interactive Mode when we type a command and press Enter, in the very next step we get the output. Interactive
Mode is very convenient for writing very short lines of code.

**Q18. Describe the script mode of Python language.** → c08
To write long Python codes or programs having multiple lines, script mode is the appropriate way. In this mode the
code is written in the Python editor and saved with a ".py" extension. In this mode we can save and edit the file.

**Q19. What do you know about Python IDLE?** → c08
The installer for Windows installs an IDLE module by default. IDLE is an acronym for Integrated Development and
Learning Environment. It is used in script mode for creating, editing and executing Python programs.

**Q20. Why do we use GIMP for drawing?** → c09
There are a large variety of painting tools in GIMP which can be used to paint our drawings beautifully. These tools
can also be used to draw, paint and modify images.

**Q21. Enlist the names of some common tools used for drawings in GIMP?** → c09
1. The bucket fill tool (fills colour in an area) 2. Gradient tool 3. Paintbrush tool 4. Pencil tool 5. Eraser tool
`[FIX]` the sheet lists "Fill colour in an area" as item 2; it describes the bucket fill tool.

**Q22. Why do we use the paintbrush tool in GIMP?** → c09
The paintbrush tool allows us to paint using fuzzy brush strokes. All strokes are rendered using the currently
selected brush type.

**Q23. What is the use of the pencil tool in drawing?** → c09
The pencil tool is used to draw free-hand lines having hard edges. It is similar to the paintbrush tool but the pencil
tool does not produce fuzzy edges.

**Q24. Is the Eraser tool important while drawing in GIMP?** → c09
The eraser tool is a very important tool for drawing because it is used to remove areas of colour from an image or
the selected part of an image.

**Q25. What is the use of the clone tool in GIMP?** → c10
In GIMP the clone tool reproduces the selected parts in an image. It copies the selected parts of the image and
pastes them in any other part of the image.
